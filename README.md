# Zoom Clone Pro

A professional, self-hosted video conferencing platform with all Zoom-like features.

## Features

- ✅ **Video Conferencing** - HD video with up to 100 participants
- ✅ **Screen Sharing** - Share your entire screen or specific windows
- ✅ **Audio/Video Controls** - Mute/unmute, video on/off
- ✅ **Chat** - Real-time messaging with history
- ✅ **Recording** - Record meetings (host only)
- ✅ **Participants List** - See who's in the meeting
- ✅ **Hand Raise** - Participants can raise hands
- ✅ **Polls** - Create and vote on polls
- ✅ **Breakout Rooms** - Split into smaller groups
- ✅ **Waiting Room** - Host approval for joining
- ✅ **Professional UI** - Modern, responsive design
- ✅ **Self-Hosted** - Complete control of your data

## System Requirements

- **OS**: Windows 10/11, macOS, or Linux
- **CPU**: 4+ cores recommended
- **RAM**: 8GB+ recommended
- **Internet**: 10+ Mbps upload/download
